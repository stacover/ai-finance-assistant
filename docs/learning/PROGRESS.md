## 已知待处理项

- M1：Prompt 写 `FAILED`，工具业务结果枚举实际为 `FAILURE`，需要统一提示词契约；Trace 的 `FAILED` 可保持其自身语义。
- M1：预算耗尽与模型抛异常时保留 Trace 已通过回归；空/畸形模型响应和 ToolCallingManager 抛异常仍可能直接抛出，需要后续单独处理。不要将当前测试结果解释成覆盖全部失败路径。
- M2：PDF 降级解析使用 `pageNumber`，当前检索读取 `page_number`；需统一来源元数据并验证页码。
- M4：Mock 资金流异常计数器在同一服务实例的多个请求间共享调用计数，不能作为每次请求固定“前两次失败”的测试机制；专项测试应使用独立可控夹具。
- M6：原 README 主要介绍配置中心，包含尚未核对的配置模板引用；部署阶段补齐并实际验证。
