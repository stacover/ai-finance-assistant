- M2：PDF 降级解析使用 `pageNumber`，当前检索读取 `page_number`；需统一来源元数据并验证页码。
- M4：Mock 资金流异常计数器在同一服务实例的多个请求间共享调用计数，不能作为每次请求固定“前两次失败”的测试机制；专项测试应使用独立可控夹具。
