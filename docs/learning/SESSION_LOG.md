## 2026-09-20：确认停止语义，补齐结果结构

**用户学习证据：** 对第 8 轮工具成功但未再调用模型的场景，用户回答“不能，最终执行的结果，进度”，即不能标记研究完成，应返回已有结果和执行进度。当前记录为 L1 场景理解，尚未完成编码实践。

## 2026-09-20：设计单次运行的已耗尽调用记录

**用户反馈：** “好”，同意继续讲解；该回复不作为已经掌握概念的证据。

**本次讲解：** 调用 ID 用于匹配某次调用和响应；判断重复业务请求需要看工具名和参数，例如 getSectorCapitalFlow + 半导体。记录生命周期限定为一次 AgentService.run，同一运行内命中耗尽记录才拦截，不影响不同参数和后续新运行。

**拟定策略：** 执行每个工具之前查询已耗尽记录；实际技术重试耗尽后登记；命中时不再访问数据源，给当前工具调用返回有明确原因的失败结果，使 Agent 能继续选择其他来源或说明限制。不简单丢弃调用，也不把所有 retriable=false 都解释成耗尽（参数错误同样可能为 false）。该策略仍在教学设计阶段，尚未接入生产调用链。
